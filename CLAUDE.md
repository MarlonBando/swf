# swf

This repo is the owner's personal software factory (see README.md and docs/design.md).

When the owner wants a ticket, task, feature, bug fix or idea for one of their projects, use the
`swf-ticket` skill (`.claude/skills/swf-ticket/SKILL.md`). Never add the `swf:ready` label unless
the owner explicitly says the ticket is ready.

Changes to the factory itself (workflows in `.github/workflows/`, docs, the skill) are normal code
changes to this repo.
